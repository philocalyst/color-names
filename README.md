Hi! This is the colorsnamed family of crates! This is a series of crates that provide... a insane range of named colors! The parent project is https://github.com/meodai/color-names, so please check it out! It uses an enum interface, and you can get generic colors in linebenders Color struct, or the RGBA crate :0

Color backends are behind features: `color` (on by default) exposes `color()` returning a linebender `OpaqueColor<Srgb>`, `palette` exposes `palette()` returning a `palette::Srgb`, and `to_rgba8()` returning an `rgb::RGBA<u8>` is always available. Enable `palette` to get both, or opt out of the default with `default-features = false` to pick exactly what you want, e.g. `colorsnamed = { version = "0.2.3", default-features = false, features = ["basic", "palette"] }`.
